# Join

## What is Join?

Join is a Kanban-based project management tool designed to help you organize tasks, manage projects, and collaborate with others.

Kanban is a method for visualizing work and tracking the progress of individual tasks. In Join, tasks are displayed as cards on a board and organized into different sections depending on their current status.

Join was developed as part of a web development project at the Developer Akademie. It is intended for educational purposes and is not designed for extensive business use.

## Features

Join provides several features to help organize tasks and contacts:

- User registration and login
- Guest login
- Summary overview
- Kanban board
- Creating, editing, and deleting tasks
- Moving tasks between different board sections
- Task priorities
- Task categories
- Assigning contacts to tasks
- Creating and managing contacts
- Subtasks with progress tracking
- Task search
- Responsive design for desktop, tablet, and mobile devices

## How to use it

### 1. Login and Registration

When opening Join, you can log in with an existing account or create a new account.

To create an account, select **Sign up** and enter your name, email address, and password.

If you only want to explore Join without creating an account, you can use the **Guest Log in** option.

### 2. Summary

After logging in, the Summary page gives you a quick overview of your current tasks.

It shows information such as the total number of tasks and how many tasks are currently in different stages of the workflow.

This allows you to quickly understand the current state of your board.

### 3. Exploring the Board

Open the **Board** to see an overview of all your tasks.

Tasks are organized into four sections:

- To do
- In progress
- Await feedback
- Done

This allows you to quickly see the current status of each task.

### 4. Creating Contacts

Before assigning tasks, you can add contacts to your project.

Go to the **Contacts** section and select **Add new contact**.

Enter the contact's:

- Name
- Email address
- Phone number

After creating the contact, it becomes available when assigning users to tasks.

### 5. Managing Contacts

Select a contact from the contact list to view their details.

Existing contacts can be edited to update their name, email address, or phone number. Contacts that are no longer needed can also be deleted.

When editing or creating contacts, the entered information is validated to prevent invalid names, email addresses, and phone numbers.

### 6. Adding Tasks

To create a new task, open **Add Task** or use the add-task option on the Board.

You can enter information such as:

- Title
- Description
- Due date
- Priority
- Category
- Assigned contacts
- Subtasks

Required fields must be completed before the task can be created.

After entering the task information, select **Create Task** to add it to the Board.

### 7. Task Priorities

Tasks can be assigned different priority levels:

- Urgent
- Medium
- Low

The priority helps indicate which tasks require more attention.

### 8. Assigning Contacts

Contacts can be assigned to a task while creating or editing it.

Assigned contacts are displayed on the task card using their initials, making it easy to see who is associated with a task.

Multiple contacts can be assigned to the same task.

### 9. Moving Tasks

Tasks can be moved between the different sections of the Board.

Move a task from **To do** to **In progress** when work begins.

If the task requires feedback, move it to **Await feedback**.

Once the task has been completed, move it to **Done**.

This makes it easy to keep track of the progress of your project.

### 10. Editing Tasks

Select a task on the Board to open its details.

From there, you can edit information such as:

- Title
- Description
- Due date
- Priority
- Assigned contacts
- Subtasks

Save your changes when you are finished.

### 11. Deleting Tasks

Open the task you want to remove and select **Delete**.

Deleted tasks are permanently removed from the Board, so make sure that the task is no longer needed before deleting it.

### 12. Using Subtasks

Subtasks allow you to divide a larger task into smaller steps.

When a subtask is completed, you can mark it as done.

The task displays the progress of its subtasks, allowing you to quickly see how much work has already been completed.

### 13. Searching for Tasks

Use the search field on the Board to quickly find a specific task.

Enter a task title or keyword. Join will display the tasks that match your search.

### 14. Responsive Design

Join is designed to work on different screen sizes.

The interface adapts to desktop, tablet, and mobile devices so that the Board, Contacts, Summary, and task management features can also be used on smaller screens.

## Navigation

The main navigation provides access to:

- Summary
- Add Task
- Board
- Contacts

Additional pages such as **Help**, **Privacy Policy**, and **Legal Notice** can also be accessed through the interface.

## Data Storage

Join uses Firebase to store application data such as tasks, contacts, and user-related information.

User authentication is also handled through Firebase.

## Technologies / computer languages

Join was built using:

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Realtime Database

## Need more help?

If something does not work as expected, try refreshing the page or logging in again.

When creating or editing tasks and contacts, make sure that all required fields are filled in correctly.

You can also open the **Help** section inside Join for additional information about using the application.
